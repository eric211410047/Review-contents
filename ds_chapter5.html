二元樹的基本概念

二元樹的定義

二元樹是由節點所組成的有限集合，允許：

  • 空集合，即樹中沒有任何節點
  • 只有1個元素，即樹中的樹根
  • 1個樹根+2棵彼此間沒有交集的二元樹(左子樹+右子樹)

特色：樹上的任何一個節點分支度不會超過2

二元樹和樹的差異：二元樹允許是空集合

二元樹的重要定理

定理1：節點數量上限

二元樹第L階的節點最多2L-1個節點，L ≥ 1

證明：

  • L = 1，二元樹第1階的節點只包含20=1個節點，即樹根(Root)
  • 假設L = N-1成立，二元樹第(N-1)階的節點最多2N-2個節點成立
  • L = N，因為第(N-1)階每個節點最多含有2個子樹，故二元樹第N階的節點最多2*2N-2 = 2N-1

定理2：總節點數量上限

深度為K的二元樹，節點最多2K-1，K ≥ 1

證明：

  • 基於定理1，二元樹第L階的節點最多2L-1個節點，L ≥ 1
  • 深度為K的二元樹最多節點數 = 階層1最多的節點數量 + 階層2最多的節點數量 + ... + 階層K最多的節點數量
  • = 1 + 2 + ... + 2K-1 = 20 + 21 + ... + 2K-1 = (1-2K)/(1-2) = 2K-1

定理3：葉節點與分支節點關係

對於任何1個非空二元樹T，令n0表示樹葉節點的個數，n2表示分支度為2節點的個數，則n0 = n2 + 1

證明：

  • 令n1表示分支度為1節點的個數
  • 令n表示T的節點個數，因此n = n0 + n1 + n2
  • 令E表示T的邊數
  • 除了Root外，每1個節點均被1條邊指向，因此n = E + 1
  • 在所有的邊中，Degree = 2節點貢獻2條邊，Degree = 1節點會貢獻1條邊
  • 即E = 2n2 + 1*n1 = 2n2 + n1
  • n = E + 1 = (2n2 + n1) + 1 = n0 + n1 + n2
  • 因此n0 = n2 + 1

特別的二元樹

1. 歪斜樹 (Skewed Tree)

2. 完全二元樹或完滿二元樹 (Full Binary Tree)

定義：深度為K並且具有最多節點數量(2K-1)的二元樹，其中K ≥ 0

3. 完整二元樹 (Complete Binary Tree)

前提：給二元樹上的節點編號，編號規則從Root開始，編號為1，同階層順序由左至右開始編號，不同階層順序由上至下開始編號

課本定義：一個含有n個節點且深度為K的二元樹是完整二元樹，若且為若它的節點和一個深度為K的完全二元樹，從編號1到n的節點均一致

一個深度為K的二元樹，若為完整二元樹，則滿足以下條件：

  • 第1層到第K-1層的節點Degree均為2
  • 假設第K層的第i個節點編號為ki，若節點ki的Degree = 1須滿足以下兩條件：
    • 節點ki只有左子樹
    • 節點k1到節點ki-1的Parent之Degree均為2

定理：一個含有n個節點的完整二元樹，其深度為log2(n+1)

陣列表示法

陣列表示法定理

如果1個具有n個節點的完整二元樹是以由上至下，同階層由左至右的順序進行編號，那麼對於任何一個Index = i的陣列元素，其中1 ≤ i ≤ n：

  • 如果i ≠ 1，即節點不為Root，其Parent Index = ⌊i/2⌋，如果i = 1，該節點沒有Parent
  • Left Child的位置 = 2i，其中2i ≤ n，反之，沒有Left Child
  • Right Child的位置 = 2i + 1，其中2i + 1 ≤ n，反之，沒有Right Child

Left Child位置的證明

證明：Left Child的位置 = 2i，其中2i ≤ n，反之，沒有Left Child

[數學歸納法]

  • i = 1，表示該節點為Root，其Left Child必在i = 2*1=2的位置，除非2i > n
  • 假設i = j-1成立，即節點j-1的Left Child位置 = 2*(j-1)
  • 令i = j，節點j-1的Right Child位置 = 2*(j-1)+1，節點j的Left Child = 節點j-1的Right Child位置 + 1 = 2*(j-1)+1+1 = 2j
  • 因此，依據數學歸納法，Left Child的位置 = 2i，其中2i ≤ n得證

鏈結串列表示法

Node 資料結構

struct Node {
    int data;           // 節點資料
    struct Node* left;  // 左子節點指標
    struct Node* right; // 右子節點指標
};

在鏈結串列表示法中，每個節點包含：

  • data：儲存節點的資料值
  • left：指向左子節點的指標
  • right：指向右子節點的指標

二元樹的走訪 (Traversal)

拜訪樹上每個節點一次，有三種拜訪順序：

  • 前序走訪法(Preorder Traversal)：中間節點→左子樹→右子樹
  • 中序走訪法(Inorder Traversal)：左子樹→中間節點→右子樹
  • 後序走訪法(Postorder Traversal)：左子樹→右子樹→中間節點
