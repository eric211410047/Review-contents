二元樹的表示方式與走訪

二元樹的表示方式

1. 陣列表示法

對於一個具有n個節點的完整二元樹，如果按照由上至下，同階層由左至右的順序進行編號，則：

  • 如果 i ≠ 1（非根節點），其父節點索引 = ⌊i/2⌋
  • 左子節點的位置 = 2i（當 2i ≤ n 時）
  • 右子節點的位置 = 2i + 1（當 2i + 1 ≤ n 時）

2. 鏈結串列表示法

typedef struct Node {
    int data;
    struct Node* left;
    struct Node* right;
} Node;

二元樹的走訪方法

1. 前序走訪（Preorder Traversal）

順序：中間節點 → 左子樹 → 右子樹

走訪順序：1, 2, 4, 8, 9, 5, 10, 11, 3, 6, 12, 13, 7, 14, 15

2. 中序走訪（Inorder Traversal）

順序：左子樹 → 中間節點 → 右子樹

走訪順序：8, 4, 9, 2, 10, 5, 11, 1, 12, 6, 3, 14, 7, 15

3. 後序走訪（Postorder Traversal）

順序：左子樹 → 右子樹 → 中間節點

走訪順序：8, 9, 4, 10, 11, 5, 2, 12, 13, 6, 14, 15, 7, 3, 1
