Agent 實現案例 - 盲狗

本章節將介紹一個簡單的Agent實現案例：盲狗。這是一個在簡單環境中運行的Agent，用於展示Agent的基本結構和工作原理。

1. 環境描述

假設這個公園，只有單一條直路可行走。所以盲狗的移動只有最簡單的一種：move down。而且在隨機的格子裡，會有食物、水。

圖1：盲狗的環境 - 單一直路

在這個環境中，盲狗只能感知當前格子中的內容，並根據感知做出相應的動作。

2. 盲狗的感知與動作

在公園裡，最簡單的盲狗，應該要有以下與環境作用的要求：

感知 (Percept) 動作 (Action)
Feel Food eat
Feel Water drink
Feel Nothing move down
圖2：盲狗的感知與動作流程

盲狗的工作流程如下：

  1. 感知當前格子中的內容（食物、水或空）
  2. 根據感知選擇相應的動作（吃、喝或向下移動）
  3. 執行選定的動作
  4. 重複以上步驟，直到到達路的盡頭

3. 盲狗的實現

這隻盲狗，只會往單一個方向移動，所以只要有食物或水，在走到底之前，就會發現這些東西。是簡單反射型 Agent，只具有最低的 AI。

// 盲狗的簡單實現 class BlindDog { constructor() { this.position = 0; // 初始位置 this.foodEaten = 0; // 吃到的食物數量 this.waterDrunk = 0; // 喝到的水數量 } // 感知函數 perceive(environment) { return environment[this.position]; } // 動作函數 act(percept) { if (percept === 'food') { this.foodEaten++; return 'eat'; } else if (percept === 'water') { this.waterDrunk++; return 'drink'; } else { this.position++; return 'move down'; } } // 運行函數 run(environment) { while (this.position < environment.length) { const percept = this.perceive(environment); const action = this.act(percept); console.log(`位置: ${this.position}, 感知: ${percept}, 動作: ${action}`); } return { foodEaten: this.foodEaten, waterDrunk: this.waterDrunk }; } } // 示例環境 const environment = ['empty', 'food', 'empty', 'water', 'empty', 'empty']; const dog = new BlindDog(); const result = dog.run(environment); console.log(`結果: 吃到 ${result.foodEaten} 個食物，喝到 ${result.waterDrunk} 個水`);
圖3：盲狗的執行過程示例

4. 盲狗的局限性

如果食物、水會在走過後才隨機出現，則不會回頭的盲狗就會錯過！所以，如果可以把移動的方向改為走到沒路會再回頭也是走到底，可能更好。

圖4：盲狗的局限性 - 無法回頭發現新出現的資源

為了改進盲狗的性能，我們可以實現一個能夠來回移動的盲狗：

// 改進的盲狗實現 - 可以來回移動 class ImprovedBlindDog { constructor() { this.position = 0; // 初始位置 this.direction = 1; // 1表示向右，-1表示向左 this.foodEaten = 0; // 吃到的食物數量 this.waterDrunk = 0; // 喝到的水數量 this.visited = new Set(); // 記錄已訪問的位置 } // 感知函數 perceive(environment) { return environment[this.position]; } // 動作函數 act(percept) { if (percept === 'food') { this.foodEaten++; return 'eat'; } else if (percept === 'water') { this.waterDrunk++; return 'drink'; } else { // 記錄已訪問的位置 this.visited.add(this.position); // 更新位置和方向 this.position += this.direction; // 如果到達邊界，改變方向 if (this.position >= environment.length - 1) { this.direction = -1; } else if (this.position <= 0) { this.direction = 1; } return 'move ' + (this.direction > 0 ? 'down' : 'up'); } } // 運行函數 run(environment) { let steps = 0; const maxSteps = environment.length * 2; // 設置最大步數，避免無限循環 while (steps < maxSteps) { const percept = this.perceive(environment); const action = this.act(percept); console.log(`位置: ${this.position}, 感知: ${percept}, 動作: ${action}`); steps++; } return { foodEaten: this.foodEaten, waterDrunk: this.waterDrunk, visitedPositions: this.visited.size }; } }

5. 盲狗的擴展可能性

如果公園變為 2D 的情況，則會有更多變化。而且，如果盲狗可以有記憶，或是更有移動活力、或是有更遠的感應能力也會表現更好。

圖5：2D環境中的盲狗

在2D環境中，盲狗可以有更多的移動選擇：

  • 上下左右移動：不再局限於單一方向
  • 記憶能力：記錄已訪問的位置，避免重複訪問
  • 更遠的感應能力：可以感知周圍多個格子的內容
  • 路徑規劃：可以規劃最短路徑到達目標

這些改進可以使盲狗在2D環境中更有效地尋找食物和水。
