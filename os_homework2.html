Q1. Describe the relationship between an API, the system-call interface, and the operating system.

The relationship between them is foundational to how software interacts with hardware and other software components.

圖1：API、系統調用接口與作業系統的關係

關鍵概念

  • API (Application Programming Interface) 提供應用程序與作業系統交互的標準方法
  • 系統調用接口是API與作業系統內核之間的橋樑
  • 作業系統通過系統調用接口提供底層硬件資源的訪問

Q4. What are the differences between the multiprogramming and multitasking structures?

The difference between them is that Multiprogramming allows multiple programs store in memory at the same time, with the CPU executing one at a time, and Multitasking allows multiple tasks to share the CPU by switching between them.

圖4：多程序與多任務的比較

主要區別

  • 多程序：多個程序同時存在於內存中，但CPU一次只執行一個程序
  • 多任務：多個任務共享CPU，通過時間片輪轉在任務之間切換
  • 多程序是程序級別的切換，多任務是任務級別的切換
  • 多任務實現了真正的並發執行，而多程序只是提高了CPU利用率
