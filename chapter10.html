格子世界中的機率推論

情境一：獨立陷阱機率

1. 問題描述

在一個 4 * 4 的格子世界中，每個格子有 0.2 的機率有坑，但我們已知以下資訊：

  • (1,1) 一定沒有坑，且 (1,2) 與 (2,1) 也沒有坑。
  • 微風規則：若某格有坑，則其四鄰域都會偵測到微風 (breeze)。
  • 觀察結果：
    • (1,1) 無微風： b_{1,1} = False
    • (1,2) 有微風： b_{1,2} = True
    • (2,1) 有微風： b_{2,1} = True

我們的目標是計算以下三個格子有坑的條件機率：

  • (1,3) 有坑的機率： P(p_{1,3} | E)
  • (2,2) 有坑的機率： P(p_{2,2} | E)
  • (3,1) 有坑的機率： P(p_{3,1} | E)

其中， E 代表我們已知的證據。

2. 微風條件分析

根據微風規則：

  • 對(1,2)來說： 鄰近格子 (1,1), (1,3), (2,2) 因為 (1,1)無坑，則至少滿足：p_{1,3} or p_{2,2}= True
  • 對(2,1)來說： 鄰近格子(1,1), (2,2), (3,1) 因為(1,1) 無坑，則至少滿足：p_{2,2} or p_{3,1} = True

設 A = p_{1,3} , B = p_{2,2} , C = p_{3,1} 則證據條件為： (A or B) and (B or C)

3. 計算可能配置的機率

根據先驗機率， A, B, C 各自有： P(A= True ) = 0.2, , P(A= False ) = 0.8

類似地， B, C 也滿足相同的先驗機率。

我們列舉所有可能的 (A, B, C) 組合，並計算符合證據條件的先驗機率：

A B C 證據條件

4. 計算條件機率

滿足證據條件的總機率： Z = 0.008 + 0.032 + 0.032 + 0.032 + 0.128 = 0.232

計算每個目標格子的條件機率：

  • P(A= True | E) = (0.008 + 0.032 + 0.032) /0.232 = 0.310
  • P(B= True | E) = (0.008 + 0.032 + 0.032 + 0.128 )/0.232 = 0.862
  • P(C= True | E) = (0.008 + 0.032 + 0.032 )/0.232 = 0.310

最終結果：P(p_{1,3} | E) = 31.0%, , P(p_{2,2} | E) = 86.2%, P(p_{3,1} | E) = 31.0%

5. 總結

  • 根據微風條件推導，建立條件公式： (A or B) and (B or C) 。
  • 枚舉所有可能 (A, B, C) 組合，計算滿足條件的總機率 Z 。
  • 透過正規化計算出條件機率。最終(1,3)和(3,1)有坑的機率約為 31.0%，而(2,2)機率則高達 86.2%！

6. 陷阱機率變化的影響

重新計算於方格[1,3]和方格[2,2]有陷阱的機率，假設每個方格的固定事前陷阱坑機率改變為0.01，試描述此時的情況與改變前機率 0.2 的情況，有那些較明顯的改變？

首先，我們重新計算圖 12.6 中每個模型的 P(frontier)。

P13,P22,P31 三個格子有 8 種組合，其中三個 P13=True, 兩個 P13=False

P1,3 = true 的三個模型的機率分別為 0.0001、0.0099、0.0099；

P1,3 = false 的兩個模型的機率分別為 0.0001、0.0099。

則 P(P1,3 | known, b)

=α ′< 0.01(0.0001 + 0.0099 + 0.0099), 0.99(0.0001 + 0.0099) > ≈ <0.1674, 0.8326>

P2,2 = true 的四個模型的機率分別為 0.0001、0.0099、0.0099、0.9801；

P2,2 = false 的模型的機率為 0.0001。

則 P(P2,2 | known, b)

= α ′< 0.01(0.0001 + 0.0099 + 0.0099 + 0.9801), 0.99 × 0.0001> ≈ <0.9902,0.0098>。

這意味著 [2,2]幾乎肯定會死亡；機率代理可以計算出這一點，並選擇 [1,3] 或 [3,1]。

此時它的死亡機率為 0.1674，而一個在三個方塊中隨機選擇的邏輯代理的死亡機率為 (0.1674 +0.9902 + 0.1674)/3 = 0.4416。

[2,2] 更可能是個陷阱的原因：

這個案例的條件是，如果它不是一個坑，那麼 [1,3] 和 [3,1] 都必須包含坑，但這不太可能。

事實上，隨著坑的先驗機率趨向於 0，[2,2] 的後驗機率趨向於 1。

情境二：固定陷阱數量

1. 方法二計算

假設與聯合分佈

  • 固定 3 個陷阱， C(15,3) = 455 種配置，每種機率 1/455 。
  • P_{i,j} 和 P_{k,l} 不獨立，因陷阱總數固定。
  • 聯合分佈： P(P_{1,2}, ... , P_{4,4}) 為 1/455 （若恰有 3 坑），否則為 0。

滿足 b 的配置

從圖 12.6：

P_{1,3} = 1 （3 個模型，2 或 3 個陷阱）：

  1. (1,1,1) ：3 坑，1 種配置。
  2. (1,1,0) ：2 坑，剩 10 格選 1 坑， C(10,1) = 10 。
  3. (1,0,1) ：2 坑，剩 10 格選 1 坑， C(10,1) = 10 。

總數： 1 + 10 + 10 = 21 。

P_{1,3} = 0（2 個模型，1 或 2 個陷阱）：

  1. (0,1,1) ：2 坑，剩 10 格選 1 坑， C(10,1) = 10 。
  2. (0,1,0) ：1 坑，剩 10 格選 2 坑， C(10,2) = 45 。

總數： 10 + 45 = 55 。

P_{2,2} = 1（4 個模型）：

  • (0,1,0) ： C(10,2) = 45 。
  • (0,1,1) ： C(10,1) = 10 。
  • (1,1,0) ： C(10,1) = 10 。
  • (1,1,1) ： C(10,0) = 1 。

總數： 45 + 10 + 10 + 1 = 66 。

P_{2,2} = 0：

  • (1,0,1) ： C(10,1) = 10 。

總滿足 b 的配置

[ 21 + 55 = 76 ]

機率計算

  • P(P_{1,3} | known, b) = 21 / 76 = 0.276 (27.6%)。
  • P(P_{2,2} | known, b) = 66 / 76 = 0.868 (86.8%)。
