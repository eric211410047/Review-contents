問題解決智能 - 倒水問題

問題描述

有 3, 7, 13 的水壺各一個，每次操作，只可倒滿或全倒在地上或倒入其他水壺。目標是要倒出 4 的水。

問題形式化

解答：

(0) 狀態：就是三個水壺內的水量 [x, y, z]

(1) 初始狀態：三個水壺的值是 [0, 0, 0]

(2) 行動：倒滿水，倒入其他水壺，或全倒在地上

(3) 轉移模型（或稱為後繼函數）：

如果現在的值是 [x, y, z]，那麼可以產生的下一狀態是：

a. 倒滿水： [3, y, z], [x, 7, z], [x, y, 13]

b. 全倒在地上： [0, y, z], [x, 0, z], [x, y, 0]

c. 倒入其他水壺：對於任何具有值為 x 和 y 的兩個水壺，現在要將 y 倒入 x；那麼 x 的水壺會改變為 min((x + y), x 最大容量)，同時也將水壺 y 減去（x 水壺所增加的量）

(4) 目標測試：要得到 4 單位在 x,y 或 z 任何一個水壺，也就是： [4,y,z] 或 [x,4,z] 或 [x,y,4]

(5) 路徑成本：執行倒水的次數

(6) 找到解決方案！步驟如下（[3L 壺, 7L 壺, 13L 壺]）：

步驟 0: (0, 0, 0)

步驟 1: (0, 7, 0)

步驟 2: (3, 4, 0)

簡單問題解決代理的虛擬碼

function SIMPLE-PROBLEM-SOLVING-AGENT(s) returns an action persistent: seq, an action sequence. Initially empty state, a description of the current world state goal, a goal to be achieved problem, a problem formulation state ← UPDATE-STATE(state,s) if seq is empty then goal ← FORMULATE-GOAL(state) problem ← FORMULATE-PROBLEM(state,goal) seq ← SEARCH(problem) if seq is empty then return a null action action ← FIRST(seq) seq ← REST(seq) return action

問題解決代理的四個階段

  • 目標設定：代理人設定要達到布加勒斯特的目標
  • 問題形式化：代理人設計狀態和動作的描述
  • 搜尋：代理人在模型中模擬動作序列，搜尋直到找到達到目標的動作序列
  • 執行：代理人一次執行解決方案中的動作

問題變體

情境調整：從「簡單目標搜尋」轉變為「最佳化問題」。目標調整為不僅要測量 4L 水，而且要以「最少的水浪費量」達成目標。
