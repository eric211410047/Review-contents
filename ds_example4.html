二元樹走訪 (Tree Traversal)

程式碼

// 二元樹節點結構
#include 
#include 

// 定義二元樹節點結構
typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

// 創建新節點的函數
TreeNode* createNode(int value) {
    TreeNode* newNode = (TreeNode*)malloc(sizeof(TreeNode));
    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}

// 前序遍歷 (Preorder): 根->左->右
void preorder(TreeNode* root) {
    if (root != NULL) {
        printf("%d ", root->data);
        preorder(root->left);
        preorder(root->right);
    }
}

// 中序遍歷 (Inorder): 左->根->右
void inorder(TreeNode* root) {
    if (root != NULL) {
        inorder(root->left);
        printf("%d ", root->data);
        inorder(root->right);
    }
}

// 後序遍歷 (Postorder): 左->右->根
void postorder(TreeNode* root) {
    if (root != NULL) {
        postorder(root->left);
        postorder(root->right);
        printf("%d ", root->data);
    }
}

int main() {
    // 創建圖中的二元樹
    TreeNode* root = createNode(17);
    root->left = createNode(8);
    root->right = createNode(26);
    root->left->left = createNode(4);
    root->left->right = createNode(11);
    root->right->right = createNode(31);
    root->right->right->left = createNode(27);

    // 輸出三種遍歷結果
    printf("前序遍歷 (Preorder): ");
    preorder(root);
    printf("\n");

    printf("中序遍歷 (Inorder): ");
    inorder(root);
    printf("\n");

    printf("後序遍歷 (Postorder): ");
    postorder(root);
    printf("\n");

    // 釋放記憶體
    free(root->left->left);
    free(root->left->right);
    free(root->right->right->left);
    free(root->right->right);
    free(root->right);
    free(root->left);
    free(root);

    return 0;
} 
}

程式說明

本程式實現了二元樹的三種基本走訪方法：

  1. 前序走訪 (Preorder Traversal)：先處理根節點，再處理左子樹，最後處理右子樹。
  2. 中序走訪 (Inorder Traversal)：先處理左子樹，再處理根節點，最後處理右子樹。
  3. 後序走訪 (Postorder Traversal)：先處理左子樹，再處理右子樹，最後處理根節點。

每種走訪方法都使用遞迴方式實現，當遇到空節點時返回。

走訪過程

1. 前序走訪 (Preorder Traversal)

走訪順序：中間節點 → 左子樹 → 右子樹

走訪過程：

  1. 1. 1
  2. 2. 1,2
  3. 3. 1,2,4
  4. 4. 1,2,4,5
  5. 5. 1,2,4,5,3
  6. 6. 1,2,4,5,3,6
  7. 7. 1,2,4,5,3,6,7

2. 中序走訪 (Inorder Traversal)

走訪順序：左子樹 → 中間節點 → 右子樹

走訪過程：

  1. 4
  2. 4,2
  3. 4,2,5
  4. 4,2,5,1
  5. 4,2,5,1,6
  6. 4,2,5,1,6,3
  7. 4,2,5,1,6,3,7

3. 後序走訪 (Postorder Traversal)

走訪順序：左子樹 → 右子樹 → 中間節點

走訪過程：

  1. 4
  2. 4,5
  3. 4,5,2
  4. 4,5,2,6
  5. 4,5,2,6,7
  6. 4,5,2,6,7,3
  7. 4,5,2,6,7,3,1

應用場景

  • 前序走訪：常用於複製樹結構、序列化樹、表達式樹的前綴表示
  • 中序走訪：常用於二元搜尋樹的排序輸出、表達式樹的中綴表示
  • 後序走訪：常用於刪除樹、計算目錄大小、表達式樹的後綴表示
