作業系統簡介

什麼是作業系統？

作業系統是一個作為電腦使用者與電腦硬體之間中介的程式。

圖1：作業系統作為使用者與硬體之間的中介

作業系統的目標：

  • 執行使用者程式並使解決使用者問題更容易
  • 使電腦系統便於使用
  • 以有效率的方式使用電腦硬體

電腦系統組織

電腦系統運作：

  • 一個或多個CPU與設備控制器通過共用匯流排連接
  • 提供對共享記憶體的存取
  • CPU和設備可以並行執行，競爭記憶體週期
圖2：電腦系統組織結構

電腦系統運作細節

  • I/O設備和CPU可以並行執行
  • 每個設備控制器負責特定類型的設備
  • 每個設備控制器都有自己的本地緩衝區
  • CPU在主記憶體和本地緩衝區之間移動數據
  • I/O操作是從設備到控制器的本地緩衝區
  • 設備控制器通過中斷通知CPU操作已完成
圖3：I/O操作與中斷機制

中斷處理機制

中斷的基本功能：

  • 中斷將控制權轉移到中斷服務程序（通過中斷向量表）
  • 中斷架構必須保存被中斷指令的地址
  • 陷阱（trap）或異常是由錯誤或用戶請求產生的軟體中斷
  • 作業系統是由中斷驅動的

中斷處理過程：

  • 作業系統通過存儲寄存器和程序計數器來保存CPU狀態
  • 確定中斷類型：
    • 輪詢（polling）
    • 向量中斷系統
  • 不同的代碼段決定每種中斷類型應採取的動作
圖4：中斷處理流程

I/O結構

同步I/O：

  • I/O開始後，只有在I/O完成時才返回用戶程序
  • 等待指令使CPU閒置直到下一個中斷
  • 等待循環（競爭記憶體訪問）
  • 一次只能有一個I/O請求，不能同時處理多個I/O

異步I/O：

  • I/O開始後，不等待I/O完成就返回用戶程序
  • 系統調用 - 請求作業系統允許用戶等待I/O完成
  • 設備狀態表包含每個I/O設備的類型、地址和狀態
  • 作業系統通過索引I/O設備表來確定設備狀態並修改表項

儲存結構

基本儲存單位：

  • 位元（bit）：最基本的儲存單位，可存儲0或1
  • 位元組（byte）：8個位元
  • 字組（word）：電腦架構的原生數據單位，由一個或多個位元組組成

儲存容量單位：

  • KB（千位元組）= 1,024 bytes
  • MB（百萬位元組）= 1,024² bytes
  • GB（十億位元組）= 1,024³ bytes
  • TB（兆位元組）= 1,024⁴ bytes
  • PB（千兆位元組）= 1,024⁵ bytes

主要儲存類型：

  • 主記憶體：
    • CPU可直接訪問的唯一大型儲存媒體
    • 隨機存取
    • 通常為揮發性儲存
  • 次要儲存：
    • 主記憶體的擴展，提供大型非揮發性儲存容量
    • 硬碟：覆蓋磁性記錄材料的金屬或玻璃盤片
    • 固態硬碟：比硬碟更快，非揮發性
圖6：儲存層次結構

快取機制

快取的基本原則：

  • 在電腦的多個層次中執行（硬體、作業系統、軟體）
  • 將使用中的資訊從較慢的儲存暫時複製到較快的儲存
  • 首先檢查較快的儲存（快取）以確定資訊是否存在
  • 如果存在，直接從快取使用資訊
  • 如果不存在，將數據複製到快取並在那裡使用

快取設計考慮：

  • 快取大小必須小於被快取的儲存
  • 快取管理是重要的設計問題
  • 需要考慮快取大小和替換策略
